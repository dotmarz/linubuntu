# Linux Administration Lab

## Overview
A hands-on Linux administration and cybersecurity learning project using Ubuntu 26.04 LTS through Windows Subsystem for Linux (WSL2).

## Environment
- Operating System: Ubuntu 26.04.1 LTS
- Platform: WSL2 on Windows 11
- Version Control: Git
- Development Tools: Python 3, pip, Git

## Skills Practiced
- Linux filesystem navigation
- Creating and editing files
- File ownership and permissions
- User and group management fundamentals
- Administrative privileges with sudo
- Package management with APT
- System troubleshooting
- Investigating phased software updates
